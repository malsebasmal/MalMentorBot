This project came about to help my younger brother with his studies.
It is a Discord bot that displays three different messages:
- Assistance.
- A prompt to run a command to view study-hour statistics.
- A message with questions at the end of the week to see how I can help.

-----

It was a lot of fun to build :)

-----

Is hosted in 2 services:

- https://render.com (Host for the bot)
- https://uptimerobot.com (Restart automatically the bot)
